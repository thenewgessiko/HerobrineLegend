# Global multiplayer NPC patch
- One NPC globally, visible to players in the same world.
- Fair round-robin selection among eligible online players (Fear >= 30).
- The selected player's Fear determines normal/aggressive stalking (existing behavior) or hunting (Fear 100).
- Personal 15-second minimum post-despawn cooldown and separate six-hunt counters.
- Existing targeted damage/effects, ambient Fear, rituals, TAB completion, cave audio and GitHub push workflow retained.
- Source patch; Maven build and live server behavior require GitHub Actions verification.
